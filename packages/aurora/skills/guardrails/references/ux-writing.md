# UX writing guardrails

Rules for user-facing copy. IDs are stable; the `[scope: …]` tag is migration metadata only — every rule is binding. See [../SKILL.md](../SKILL.md) for the scope legend.

- **WRITE-1** `[scope: design-system]` Page and section titles, DataGrid column headers, button labels, and overflow- and popup item labels must use Title Case.
