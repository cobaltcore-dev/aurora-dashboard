Fixed folders disappearing from the "All" tab of the object browser in a versioned Ceph bucket. Content would flicker in and then be replaced with "No objects found.", while the header count still showed the real number of items, and the missing folders remained visible under the "Deleted" tab. The "All" tab discarded any folder without a zero-byte placeholder object (`folder/`), which only Aurora's "Create folder" button writes, so this hit every bucket populated by another S3 client (Elektra, `s3cmd`, `rclone`, an SDK); the same check also hid a folder whose placeholder had a delete marker on it, even though the folder still had live content. The check was unnecessary in the first place: `ListObjectsV2` only ever returns current versions, so a `CommonPrefix` coming back from it already means the folder has live content, and a folder whose contents are entirely covered by delete markers never appears in the listing at all. The "All" tab now renders exactly what the listing returns. As a side effect, `versioning.checkDeletedContent` no longer runs for a normal folder view, saving up to `S3_MAX_SCAN_PAGES` (20) paginated `ListObjectVersions` requests per folder browsed; it still runs, unchanged, for the "Deleted" tab.
